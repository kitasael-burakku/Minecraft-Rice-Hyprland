KEYBINDS
========

Main modifier: SUPER (Tecla Windows / Options)


APPS
----

SUPER + Enter              Open Terminal
SUPER + E                  Open File manager
SUPER + B                  Open Browser
SUPER + Space              Open Launcher
SUPER + A                  Open/close SwayNC
SUPER + W                  Open Wallpaper selector (Rofi)
SUPER + SHIFT + W          Toggle dynamic wallpaper theming (matugen)
SUPER + M                  Open Music Player
SUPER + O                  Open OBS

WINDOWS
-------

SUPER + Q                  Close window
CTRL + ALT + V             Toggle floating
SUPER + F                  Fullscreen mode 1
SUPER + SHIFT + F          Fullscreen mode 0
ALT + TAB		           Window Switcher

SYSTEM
------

SUPER + F1		           Keybind Viewer
SUPER + F2		           Update System
SUPER + SHIFT + R		   Reload Waybar and SwayNC
SUPER + Delete             hyprshutdown (fallback: Exit Hyprland)
SUPER + Escape             Open Wlogout
SUPER + ALT + H            Lock screen
CTRL + SHIFT + Escape      Open btop
SHIFT + Escape             Open Bottom 
ALT + SHIFT                Change the keyboard layout

CLIPBOARD / COLOR
-----------------

SUPER + SHIFT + V          Clipboard history
SUPER + P                  Color picker


SCREENSHOTS
-----------

SUPER + F12                Full monitor screenshot
SUPER + F11                Region screenshot with Swappy
SUPER + F10                Active window screenshot


FOCUS
-----

SUPER + Left               Focus left
SUPER + Right              Focus right
SUPER + Up                 Focus up
SUPER + Down               Focus down


MOVE WINDOWS
------------

SUPER + SHIFT + Left       Move window left
SUPER + SHIFT + Right      Move window right
SUPER + SHIFT + Up         Move window up
SUPER + SHIFT + Down       Move window down


WORKSPACES
----------

SUPER + 1-0                Switch to workspace 1-10
SUPER + SHIFT + 1-0        Move window to workspace 1-10


SCRATCHPAD
----------

SUPER + S                  Toggle scratchpad
SUPER + SHIFT + S          Move window to/from scratchpad (toggle)


MEDIA
-----

Volume +                   Increase volume
Volume -                   Decrease volume
Mute                       Mute audio
Next                       Next track
Play/Pause                 Play/Pause
Previous                   Previous track


MOUSE
-----

SUPER + Left click         Move window
SUPER + Right click        Resize window
SUPER + Scroll down        Next workspace
SUPER + Scroll up          Previous workspace


LAYOUT SWITCHER
---------------

SUPER + SHIFT + D          Dwindle layout
SUPER + SHIFT + M          Master layout
SUPER + SHIFT + O          Scrolling layout
