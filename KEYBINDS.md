# Keybinds

Main modifier: `SUPER`

## Apps

| Keybind | Action |
|---|---|
| `SUPER + Enter` | Open terminal |
| `SUPER + E` | Open file manager |
| `SUPER + B` | Open Brave |
| `SUPER + Space` | Open launcher |
| `SUPER + A` | Open/close SwayNC |
| `SUPER + SHIFT + W` | Open wallpaper selector (Quickshell) |
| `SUPER + O` | Open OBS |
| `SUPER + CTRL + H` | Open Hyprland config in VSCodium |

## Windows

| Keybind | Action |
|---|---|
| `SUPER + Q` | Close window |
| `CTRL + ALT + V` | Toggle floating |
| `SUPER + F` | Fullscreen mode 1 |
| `SUPER + SHIFT + F` | Fullscreen mode 0 |

## System

| Keybind | Action |
|---|---|
| `SUPER + Delete` | Exit Hyprland / hyprshutdown |
| `SUPER + Escape` | Open Wlogout |
| `SUPER + ALT + H` | Lock screen |
| `CTRL + SHIFT + Escape` | Open btop |
| `SUPER + SHIFT + X` | Toggle Cava |
| `SUPER + W` | Reload Waybar |

## Clipboard / Color

| Keybind | Action |
|---|---|
| `SUPER + SHIFT + V` | Open clipboard history |
| `SUPER + P` | Open color picker |

## Screenshots

| Keybind | Action |
|---|---|
| `SUPER + F12` | Full monitor screenshot |
| `SUPER + F11` | Region screenshot with Swappy |
| `SUPER + F10` | Active window screenshot |

## Focus

| Keybind | Action |
|---|---|
| `SUPER + ←` | Focus left |
| `SUPER + →` | Focus right |
| `SUPER + ↑` | Focus up |
| `SUPER + ↓` | Focus down |

## Move Windows

| Keybind | Action |
|---|---|
| `SUPER + SHIFT + ←` | Move window left |
| `SUPER + SHIFT + →` | Move window right |
| `SUPER + SHIFT + ↑` | Move window up |
| `SUPER + SHIFT + ↓` | Move window down |

## Workspaces

| Keybind | Action |
|---|---|
| `SUPER + 1-0` | Switch to workspace 1–10 |
| `SUPER + SHIFT + 1-0` | Move window to workspace 1–10 |

## Scratchpad

| Keybind | Action |
|---|---|
| `SUPER + S` | Toggle scratchpad |
| `SUPER + SHIFT + S` | Move window to scratchpad |

## Media

| Keybind | Action |
|---|---|
| `Volume +` | Increase volume |
| `Volume -` | Decrease volume |
| `Mute` | Mute audio |
| `Next` | Next track |
| `Play/Pause` | Play/Pause |
| `Previous` | Previous track |

## Mouse

| Keybind | Action |
|---|---|
| `SUPER + Left click` | Move window |
| `SUPER + Right click` | Resize window |
| `SUPER + Scroll down` | Next workspace |
| `SUPER + Scroll up` | Previous workspace |

## Layout Switcher

| Keybind | Action |
|---|---|
| `SUPER + SHIFT + D` | Dwindle layout |
| `SUPER + SHIFT + M` | Master layout |
| `SUPER + SHIFT + O` | Scrolling layout |
